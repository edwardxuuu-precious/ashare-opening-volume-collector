# 量序界面约束

以每日筹码筛选工作台为全站视觉基准。相似操作使用相同的导航、颜色、控件状态和图表语言；页面布局服务于各自任务，不改变筛选规则、行情口径和数据状态。

## 全站基础

- 使用 `SiteHeader` 提供品牌、四项主导航、当前页标记、页面操作及账号入口。桌面顶栏高 56px；窄屏导航另起一行并可横向滚动。
- 全站使用 `globals.css` 中的 `--ui-*` 语义变量。品牌蓝为 `#345cd6`，正文为 `#192536`，次要文字为 `#647184`，边线为 `#e6eaf0`，侧栏为 `#f6f7f9`，选中背景为 `#eaf0ff`。页面不另建同义颜色。
- 涨用红色、跌用绿色。图形用 `--ui-rise` / `--ui-fall`，小号文字用对比度更高的 `--ui-rise-text` / `--ui-fall-text`。图形和文字的涨跌判断仍分别采用各自数据口径。
- 涨跌幅文字共用 `priceChangeText` 与 `priceChangeClass`。列表、选中摘要和图表都显示同样的符号与精度；未知值显示“待核实”，未知与零均使用中性色，不能被页面默认颜色覆盖。
- 查询、选择和操作控件使用浅色背景、细边框、明确的选中及键盘焦点状态；不可用操作应禁用。错误、缺失和待核实必须有文字说明，不能仅凭颜色区分。
- 登录保留独立的账号入口布局，复用品牌色、文字和输入状态；不改变登录、退出或错误处理。

## 页面与图表

- 股票名单、搜索、筛选和选中行采用浅色侧栏与蓝色选中态。首页保留单只、多只、全市场查询及其搜索、日期和筛选功能。
- 日 K 图统一浅色背景、价格和成交量分区、日期刻度、涨红跌绿与悬停读数。需要 120 根的页面仅在真实行情足够时显示 120 根；行情不足应显示实际根数。
- 日 K 读数统一使用 `CandleReadout`，依次显示日期、开、高、低、收、涨跌幅、量，筹码页追加换手率。价格与涨跌幅显示两位小数，成交量统一使用千分位、万、亿及明确的原始单位。研究数据中的“手”“原生量”或“单位待核实”不能改写成股。
- 读数跟随悬停、点按或日期查看控件；涨跌幅使用 `candleReturn`，以完整历史中的前一根已发布收盘计算，不受显示窗口裁切影响。无前收时显示“待核实”；手机宽度允许换行，不裁掉基础字段。筹码读数、右上角报价与预览日期使用同一个命中结果，移到绘图区外一同恢复固定日期。
- 周期使用 `ChartPeriodControl`，标签统一为“60根”等真实 K 线数量。行情不足显示“可用 N 根”。换股、读取更长行情或刷新相同工作台时保留所选显示周期；黄金的计算窗口仍为 60 根。
- 筹码预览与固定日期、趋势准备期与基准线、黄金画线和吸附各自保留。黄金画线可使用较大的工作区；120 根背景不改变其计算窗口。历史研究只显示观察日及以前的数据。
- 历史筹码校准页使用统一顶栏和浅色图表，但保留旧模型说明和长页面滚动，不能套用固定高度工作台容器。

## 名单与交互

- 筹码、每日趋势、趋势研究、黄金的名单共用 `stockListMatches` 与 `useStockListNavigation`。搜索忽略首尾空格和字母大小写，输入框使用搜索语义。股票名称和代码均可检索，研究名单额外支持观察日期。
- 上下键只遍历当前筛选后的完整名单，首尾不循环，空名单不切换，跨页时同步分页与名单滚动。焦点从名单行开始时随选中行移动，随后 Enter 不能跳回旧行。输入法组字、组合键、输入控件、弹窗和其他操作按钮保留自身按键行为。
- 名单为空必须显示文字说明。保留原详情的页面须明确“当前选择不在本次列表中”；筛选不能让旧详情看起来属于一个空名单。研究的导航键使用股票代码与观察日的组合，不能合并同一股票的不同证券日。
- 右侧条件与批注页签使用 `InspectorTabs`。只有活动页签进入 Tab 顺序，左右键切换，Home/End 到首尾，同时移动焦点并正确关联面板。分段按钮仍使用其原本的选择语义。
- 三类日 K 图均提供鼠标悬停、触摸点按及原生“查看K线日期”控件。该控件支持左右键、Home、End；筹码固定日期与黄金锚点微调继续按各自业务回调处理，不能重复触发全局换股或换日。

## 读取与恢复

- 初次读取区分加载、错误和完成。请求已经失败时不能继续显示“正在读取”。网络错误、没有匹配结果、行情缺失、确认未交易及模型待核实使用各自真实说明。
- 可重试的读取错误使用 `RetryMessage` 提供“重新读取”。目录、当前详情和校准筛选表各自重试；重试详情不重置股票、日期、对比日期或筛选条件。
- 已有完整结果的后台刷新失败时保留原结果及查看上下文，并显示错误与重试。相同批次的刷新不重拉已成功的详情，失败详情仍能单独恢复。黄金云端记录恢复保留草稿语义。
- 登录状态的网络读取失败提供“重新验证登录状态”，直接复查已有会话。正常的 401 继续进入账号登录，不改变认证权限。
- 日期、筛选和说明弹层通过同一个 `PopoverContent` 在视口内定位，保留边距并允许内部内容滚动。手机打开日历后选择日期、页面滚动或完成区间，操作按钮仍须留在屏幕内。

## 各页保留的任务差异

| 页面 | 日期与专有字段 | 保留的操作 |
| --- | --- | --- |
| 开盘量查询 | 单日、多日或区间；开盘量占比、量、四价及缺失状态 | 单只、多只、全市场查询、日历、排序、分享与记录详情 |
| 每日筹码 | 筹码固定日与临时预览日；主峰、平均成本、原峰区间及换手率 | 点击固定日、左右键换交易日、分布比较及预加载 |
| 每日趋势 | 已发布筛选日；准备日、缩量比例、冻结基准与当日触发 | 名单筛选与条件核对，查看旧 K 线不改变筛选日 |
| 趋势历史研究 | 观察日及以前行情；版本与研究统计 | V2/V3、时间段、证券日名单及来源；国芳单例单独保留 |
| 黄金画格 | 不可变发布批次；H/L/M、自动线与人工线 | 60 根计算、120 根背景、吸附、锚点、撤销与批注 |
| 历史筹码校准 | 旧模型样本日及人工指定对比日 | 独立样本检查、手动比较及长页面滚动 |

## 响应式与验证

- 760px 及以下使用窄屏导航和纵向布局。黄金页的批注抽屉、趋势页的中等宽度侧栏等功能性断点保留，不把不同交互强行压成同一种布局。
- 变更后检查桌面、760px 两侧及手机宽度，覆盖导航、股票搜索、日期筛选、图表、侧栏滚动、弹层、键盘焦点与加载/错误状态。黄金画线使用隔离数据验证，避免改变正式账号草稿。
- 使用同一股票、日期和周期比较相似图表；验证实际渲染及鼠标读数。生产构建不得包含公开行情数据，线上验证与本地验证分别记录。
- `tests/browser/ui-consistency.cjs` 覆盖六页的桌面与手机布局、共享读数、过滤后导航与行焦点、页签按键、触摸查看、周期保留、读取失败及上下文恢复。输入由 `UI_FIXTURE_DIR` 指向隔离快照，API 写入被阻止，不能把这些验证称为正式账号人工验收。
