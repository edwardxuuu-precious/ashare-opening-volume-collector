## 统计规则

这是当前在市沪深京全市场的独立描述统计，不叠加筹码页的低于10元、近10日收盘涨停或成本位置条件。每股保留PASS/FAIL/UNKNOWN，覆盖分母采用对应日筹码任务已经核对的完整股票清单。有效格子表示已采用研究近似下的结构有效，不能据此视为完整策略入选或群主画法已认证。

计算移植自 Filter 的 `tools/full_strategy_signals.py::structure_at`，已采用设计 `FILTER-FULL-STRATEGY-RESEARCH-DESIGN-20261015-01`，内容SHA256 `ba5ceafce205c8a674d74c36f1b5062835a3e1ba87073af3052a8d0e298a182b`。关联规则GEO-01/02/04/05/09、SIG-01，原来源S01/S03/S04/S07/M01；60/5自动选点、20/50阈值及对称子空间上沿属于已采用的研究定义，并非由工具名称推出的通用黄金比例。

- t−64至t−5共60个交易日内取最高High，同价取后；其后同窗口内取最低Low，同价取后。后续再破低，结构失效；缺少所需交易日行情保持UNKNOWN，不跳过停牌或缺行。
- 原研究结构要求跌幅至少20%。跌幅≤20%取1/2层、>20%且≤50%取1/4层、>50%取1/8层；20%等号是半层可达的唯一边界。价格线为 `L + ratio × (H−L)`，子空间上沿为 `L + 2×ratio×(H−L)`。
- 同时显示主空间50%、25%、12.5%数学线，选中轴另加标记。25%不替换成23.6%，也不凭工具名称强制0.618。
- `Low ≤ R ≤ High`为当日盘中触线。前后两日均有效且H/L日期、价格及比例均相同，才判断收盘跨线；向上为`前收 ≤ R < 今收`，向下为`前收 ≥ R > 今收`。换轴、失效或缺项返回UNKNOWN，而非制造价格突破。
- 距轴百分比为`(Close/R−1)×100`；比较使用Fraction精确数值，百分比显示保留8位小数，价格线保持终止小数。原始known_at为null，不填造历史时钟，不生成订单。
- 沿用现有2026交易日历，年初所需65日不足、缺失或不支持年份保留UNKNOWN。扩年历需要补充对应来源，不能猜休市日。

## 页面与数据

左侧按有效、全部、待核实、未形成/失效切换完整名单，支持名称/代码搜索与100条分页。点击股票显示K线、逐日对齐成交量、原H/L日期、所选子空间和价格线；盘中触线与收盘跨线单列。默认65根显示行情覆盖完整选点窗，可切120/250/500根。显示行情根数不是筹码模型窗口。

当前格子截至统一统计日，在过去K线上叠加用于观察当前空间，不表示过去各日当时已有同样格子。当前版本未实现逐历史日期重选格子。

`backend/chips/golden.py`为无I/O计算层。日更运行器逐股发布时使用已经取得的日线生成 `screening_row.golden_grid`，不再次采集行情、不改筹码计算或筹码筛选。完成全市场后，先发布不可变 `/data/chips/daily/<dataset>/golden.json`，最后条件提交现有manifest。新增源码进入日更实现身份；旧批次不会冒充新实现。

鉴权只增加上述精确GET路径，复用既有Cognito验证和私有S3读取权限。没有新增服务器、定时器、AWS资源或写API。额外工作是现有日更任务的格子算术、压缩JSON保存及读取。固定系数2、210根筹码行情和unchanged_threshold=null均保持。
