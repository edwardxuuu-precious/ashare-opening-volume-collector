# 趋势量价研究工作台

`/trend` 展示已冻结 V2/V3 在保存样本上的筛选复算。沿用量序品牌、导航、白灰蓝工作台、账号会话及私有行情接口。统计单位是证券与日期的组合；搜索和名单分类只改变列表，不改变所选时间段的统计分母。

国芳集团是原视频核对单例，独立展示，不进入面板漏选及误选分母。原参考标签、形态争议、来源缺失分别保留。代理参考标签不是用户确认标签，开发样本也不作为新增独立验证。每日入选数量只覆盖已知行情；存在来源缺失时，完整名单数量保持未知。工作台没有收益评价或订单执行。

逐例视图读取原筛选器保存的条件、候选准备日和固定成交量基准，不重新计算筛选。K线先裁到观察日，再取显示窗口。成交量保留来源原单位，跨来源不直接比较绝对量。未找到有效准备时，放量倍数保持未知，不解释为没有放量。

“下跌状态持续”单独列为尚未计算的候选定义。它没有替换冻结 V3，也没有把放量大涨直接认定为上涨趋势。黄金分割不参与此页筛选。

## 私有快照

接口只允许已认证 GET：

- `/data/trend-volume/manifest.json`。
- `/data/trend-volume/<16位小写十六进制批次>/summary.json`。
- `/data/trend-volume/<批次>/<6位证券代码>.json`。

`summary.json` 保存版本、统计范围、来源身份与索引。证券文件保存同批次行情和条件记录。前端拒绝跨批次、跨证券、矛盾状态及未来准备日。原始行情和导出文件不提交到 Git，也不放入静态构建或公共数据目录。

导出器只读取本地冻结结果及其保存的输入身份，逐个核验来源 SHA-256。它不访问行情提供方、不运行筛选器、不搜索参数。输出只允许写入仓库忽略的 `outputs/`。

```powershell
.\.venv\Scripts\python.exe -X utf8 tooling/export_trend_volume.py --filter-root D:\Codex\Filter
```

同一导出版本生成不可变批次。发布时先上传并回读该批次全部私有对象，再更新私有 manifest。认证 API 的新增路径置于原 Cognito 校验之后，不改变账号、访问权限或采集调度。网站继续使用保护构建及 Amplify 最新成功 job 并发守卫。

## 验证

`tests/frontend/trend-volume.test.mjs` 覆盖统计分母、名单分类、观察日前缀及数据身份拒绝。`tests/python/test_trend_volume_auth.py` 覆盖认证、精确路径、禁止写入、gzip、缺失与损坏载荷。实际部署还需核对静态文件身份、匿名拒绝、登录内读取及桌面和手机交互。
