# 大周期底部数据观察

入口 `/cycle-bottom`。目标为真实指数历史拟合、持续更新数据与观察；2026-11-08用户明确纠正上一版仅展示材料的实现。截图和原文只作末尾参考，不能作为本功能验收。

## 数据与来源边界

- H00300沪深300全收益：中证公开历史，2004-12-31起；不使用000300价格指数代替。
- 000012上证国债：中证公开历史，2003-01-02起；指数包含全价、利息及再投资，不是到期收益率。
- 000001上证月K：新浪不复权日线合成每月首开、最高、最低、末收；实有日线自1990-12-19起，本月未完成明确标记。
- 原885007.WI：待Wind授权接口或合法导出。[分发平台官方协议](https://app.jiucaishuo.com/html/user_server.html)§6.2.2.1(7)明确禁止机器人抓取，§13.1—13.2要求复制/转载许可。已有探针只留本地取证，未进入生产数据或无人更新任务。
- 930897「中证非纯债债券型基金指数」是页面默认的公开参照，用户于2026-11-09选择持续更新此口径，并明确与原Wind的区别。云端通过 `CYCLE_INCLUDE_NONPURE=true` 启用，缺少该变量时采集器仍只取基础来源。其选样为合同允许投资股票与可转债的债券型基金，按中证规则加权；基日2007-12-31、2016-08-31发布，基日前孤点排除，发布前属回溯数据。

930897与原885007.WI的样本、权重和基期不同，差距与触线日期不能互换。页面近图说明准确名称和差异，不将公开序列续接、估算或标注为Wind行情。原Wind历史仅在本地离线复核，生产不提供该历史序列，也未启用Wind自动更新。已有选择保留；首次进入优先显示930897，仍可切换国债。

只用真实日期交集，不补零、不向前填充。CSI实测有起点锚点及2018-06-18休市记录，原件保留、计算前剔除。2026用既有交易所日历核对，早年按新浪实有上证日期，未宣称所有历史交易日均逐日获官方认证。超出已验证日历年度仍按来源实有数据更新，但状态明确报日历待核对，不声称最新完整交易日已确认。

## 拟合与直接比较

直接模式在首个共同日归一为100，差距为 `(股票归一值/债券归一值-1)*100%`，基期明确显示。曲线交会不等于股票盈利收益率、债券到期收益率相等或估值见底。

拟合固定使用2010-01-01至2019-12-31全部共同日，以10%分位回归拟合 `log(S)=alpha+beta*log(B)`。SciPy HiGHS线性规划最小化经验pinball损失，求解上限10秒，未获最优解不发布。5%—15%训练残差带沿用同一斜率，是历史残差范围，不是置信区间或保证支撑。图上股票和拟合线按股票共同基期归一，差距为 `(实际S/拟合S-1)*100%`。

训练不含2020后数据，新增日线不移动训练窗口。但这是今天重建的历史研究，原文已列2022/2024，不能冒充当年实装、当时数据认证或真正独立前瞻验证。每版保留模型版本、来源、日期与原件SHA。训练外低于全部训练低位的天数和最低差距直接显示；仅用1e-6个百分点处理浮点误差。国债模型已有明显训练外漂移，不调线隐藏，不把负差距称为见底或预测跌幅。

2012、2016、2018、2022、2024案例用全年最低收盘日，属于事后定位，不能当时识别，不能计入触线成功率。该日无参照值就不生成该案例，不用相邻日替代。

事件分开计算：拟合为从上方进入差距≤3%；直接比较为收盘绝对差距≤3%且前一共同日在区外，两个方向均可进入。冷却均为63共同观察日，未为提高收益优化阈值。训练内回看与2020后历史核对分开。

后续126/252个股票交易日显示收盘收益和最深收盘下探；下探是未来窗口最低收盘相对进入日收盘，包含进入日，所以最多为0，不是盘中回撤或峰谷最大回撤。未成熟窗口为null，不补零；汇总只用实际事件，不混入事后年度低点。

月线通道固定以1997-07至2019-12月收盘对时间做对数OLS，按训练残差10%/50%/90%画通道，2020后外推观察。不是原作者公式或不可跌破的底部。

## 自动更新与失败处理

`.github/workflows/cycle-bottom.yml` 计划每日北京时间08:40、16:40、22:40核对，包括周末补发。仅main、公有仓库、未设置 `DISABLE_CYCLE_BOTTOM_UPDATE=true` 时自动执行，保留免费runner门；单轮10分钟、采集计算预算240秒、每源单次25秒网络界限，不自动重试限流/拒绝访问，不调用付费API。

`python -m backend.cycle_bottom.daily` 每轮取真序列重算固定模型与观察；16:30前不把当日记录当最终收盘。来源滞后按实际共同日计算并标partial；失败保留上一成功manifest，单独记录失败。相同数据只更新核对时间，不把重新检查说成行情更新。

页面可见时每60秒查已发布版本，重新聚焦也检查，支持手动刷新。失败保留旧有效数据，明确失败和最后成功时间。数据更新时间、后台核对时间、浏览器读取时间分开。观察由实际数值生成，不调用定时LLM。

私有S3前缀 `data/cycle-bottom/`：原件 `raw/<sha>.raw`，分析 `<16位版本>/analysis.json`。原件与分析写后回读，manifest最后条件写；独立concurrency保护写者。认证GET只开放manifest、status和版本analysis，不开放raw、任意文件或写接口，沿用Cognito和已有IAM权限。静态保护构建继续剥离全部data。

来源/优化/身份/日期/数值/回读失败停止本轮发布，之后计划可再核对，旧成功版本保留。新来源、Wind合法接入、规则或历史修订、跨日历年度、训练外漂移应重新审阅对应边界。页面完成、运行事实、人工接受、模型可靠性和投资结果分别记录。

## 重现与依据

完整研究/测试依赖：`.venv/bin/python -m pip install -r backend/cycle_bottom/requirements.txt PyYAML`；原采集器仍只安装根requirements。本地：

```sh
.venv/bin/python -m backend.cycle_bottom.daily --include-nonpure --out public/data/cycle-bottom --raw-dir var/data/cycle-bottom/raw
```

public/data仅本地开发、Git忽略且保护构建剥离；生产经私有桶发布。快照附来源URL、SHA、实有区间、剔除和缺口数量。测试通过不代替真实数据和线上运行验收。

- [沪深300编制方案§4.6](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000300_Index_Methodology_cn.pdf)：读取2023-09版本，支持分红再投资口径，未审计全部后续修订。
- [上证国债编制方案](https://www.sse.com.cn/market/sseindex/indexlist/indexdetails/indexmethods/c1/000012_000012hbook_CN.pdf)：名称、基日及利息再投资。
- [AKShare官方指数文档](https://akshare.akfamily.xyz/data/index/index.html)：公开历史端点及日频字段，运行用1.18.88新浪解码器。
- [SciPy linprog](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linprog.html)：稀疏线性规划、自由参数与最优状态。研究模型和阈值属于本项目，非该文档认证的投资规律。
- [930897指数单张](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/930897factsheet.pdf)、[系列方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/930889_Index_Methodology_cn.pdf)：可选参照的名称、基日、发布及选样边界，不证明原Wind规律。
