# 每日黄金画线与位置分类

入口为 `/golden/daily`，主导航显示“每日画线”。原 `/golden` 的固定20样本、人工画线和批注继续保留，通过“人工核对工作台”进入。

左侧“指定标的”列表按用户设定的顺序保留15只股票及上证指数、创业板指数，共17项。股票直接关联当前完整发布批次，不受每日分类、距离排序或严格影线筛选影响；不画、历史和数据不足的结果也保留，点击后沿用原K线和选点详情。切换回“每日分类”时保留原筛选与选择。

两个指数分别使用 `sh000001`、`sz399006`，不会与六位股票代码混配。指数与股票使用同一画线、分类和时间处理逻辑，指数点位及独立来源批次另行标注。旧批次尚无指数时保留缺结果提示；来源不足、结果尚在读取和读取失败分别显示。

## 画线依据

先检查当前波段与父子层级，再固定起点、查找次高或次低。低点向上画使用实际 Low 形成的次低，高点向下画使用实际 High 形成的次高。支撑、阻力和角色反应用于说明结构依据，不能只因价格接近就把另一个高点、低点或算术中点冒充所需的次低、次高。

- 高点 H 与中轴 M 按对数等距推算低点：`L = M²/H`。
- 低点 L 与中轴 M 按对数等距推算高点：`H = M²/L`。
- 中轴和原点取实际K线字段，推算端与实际端分别标明，不平均价位或按未来极值倒推中轴。
- 从原点到选点证据齐备时已经走过推算端，先复查预先形成的父子波段和独立候选。不能沿历史价格向左搜索直到公式通过。
- 原点或中轴归属冲突、同等候选竞争、反向证据不足时不画；详情保留原因及被拒候选。

计算使用最近60根实际日线，最多显示120根背景。左右各2根局部转折仅生成候选，不能独自证明阶段重要性。完整反应、结构延续及角色证据提供额外检查；这是一版保守的自动工程解释，不能称为对所有人工视觉判断的完全复现。具体工程定义保存在 `backend/golden_projection/policy.json`，参数哈希随结果发布。2%只用于展示距离，不作为支撑阻力聚类容差。

## 逻辑与方法：次高、次低与支撑阻力转换

本轮用户要求把左侧原支撑、跌破、右侧反弹受阻的转换关系接入共享选轴代码，再重画金种子。此前直接把右侧反弹上影线最高价当中轴的V2方法已撤回。V3的单点精确同价回测与局部极值门槛也会遗漏连续下跌中的区域支撑，本轮V4补充独立的区域转换证据，不要求来源支撑先成为局部最低点。

| 画法 | 固定起点 | 中轴实际字段 | 价格关系 | 推算端 |
| --- | --- | --- | --- | --- |
| 低点向上画 | 原低点 L | 有结构依据的次低 Low，或已确认转换的原支撑边界 Low | M > L | H = M²/L |
| 高点向下画 | 原高点 H | 有结构依据的次高 High，或已确认转换的原阻力边界 High | M < H | L = M²/H |

“次低、次高”是相对固定原点的结构角色，不是窗口内价格数值的第二名。完整反应、已有角色反应和本轮区域转换分别提供资格，不能把单独更高的Low或更低的High直接标成中轴，也不能让局部转折确认成为所有区域结构的必要前提。

整体处理顺序为：

1. 固定本轮原点、方向、父子波段和输入截止日。原点及其层级先于目标计算确定，不因哪个目标更好看或尚未到价而移动。
2. 先检查原点右侧有独立依据的实际次高或次低，保存实际字段、原价、结构资格与确认日期。
3. 右侧没有可成立组合才查左侧。包括L＝6.75、右侧Low6.77推算H＝6.79，但6.79在全部证据完成前已到过的情况。未确认、提前到价、原点被破坏分别记录。
4. 左侧候选须属于预先构造的当前波段。除既有完整反应和角色路径外，核对“原区域形成、收盘破位、当前原点、另日失败回测”的转换链。候选和来源区域先于目标检查形成，不能沿历史价格回找直到得到未到价目标。
5. 右侧组合已经成立、后来才触达或失效时，保留真实历史终态，不能把它改写成“右侧没有”再向左放大目标。同侧多个可成立结构仍保留竞争，不能按目标大小或是否到价强选。
6. 原点与轴点确定后才计算等高区间，再判断当天位置。目标触达、原点被越过和收盘跨回中轴的结束条件保持。结构结束与交易平仓分开。
7. 保存来源资格日、转换确认日、本轮组合证据日、实际记录日和下一交易日生效日。历史首次可知时间仍为未知，不把今天重算的结构倒填为历史已生效锁线。

### 区域转换与中轴取价

原支撑由至少两根下影线的非空共同交集形成，原阻力对称使用上影线交集。区域只由实际K线重叠形成，不用2%、均价聚类或ATR容差。同一来源组内的每根实际字段及日期均保留。

本轮采用明确的边界取价工程定义：向上画取共同支撑区下沿所对应的实际Low；向下画取共同阻力区上沿所对应的实际High。同价来源取最新实际K线。这不是取整片低点分布的平均值或外侧最低值，也不是直接取右侧回测上影线。该定义是本地可复现的工程选点规则，用户确认的转换关系与具体价位的用户验收分别保留。

转换链要求来源组结束、收盘完整破位、固定原点、另一个交易日失败回测依次发生。回测影线须实际触及原共同区域，实体保持在失败一侧；破位至失败回测之间不能已经收盘完整收复该区。只有右侧上影线、缺少左侧来源区域，或尚未触区、缺少破位、同日先后不明，都不能完成转换。

左侧取价点的日期与右侧确认转换的日期分开。新转换不会因确认日位于原点右侧而被排除，也不会因此放开旧角色路径的波段守卫。来源区域必须仍属于预先构造的左侧父子范围；外侧新低或新高会停止旧波段延伸，内部更高低点或更低高点沿已有父链保留。

转换关系确认后，还需本轮配对证据。待来源、破位、回测、原点及全部父链确认都可知之后，向上画等待首次收盘超过完整区域上沿，向下画等待首次收盘低于完整区域下沿。更早的收盘不能代替这项证据。既有普通左侧结构仍沿用收盘越过M的门禁，新区域转换明确使用完整区域边界。门禁是保守的工程确认处理，不作为群主新增原话。

若在上述全部证据完成前已经到过推算端，仍按既有提前到价规则拒绝；若成立后才到价或失效，仍保留历史。不同字段、来源、确认日与生命周期不能混称“无效”。来源组内没有被取作核心边界的低点仍作为结构证据保存，不能继续笼统标为“只有平台、没有转换资格”。

### 金种子本轮复核的来源链

固定L为用户确认的10月23日实际Low6.75。左侧10月16、19日共同下影线区域为7.50至7.61，原点后反弹最高7.49未触区，不能确认这组转换。10月20、21日共同下影线区域为7.41至7.43：10月20日Low7.41、实体下沿7.48，10月21日Low7.36、实体下沿7.43，二者交集给出区域。

10月22日收盘6.82跌破该区；10月26日High7.39尚未触区；10月27日上影覆盖该区、收盘7.30及实体均在下方，成为右侧失败回测证据。11月2日收盘7.72才完整收复该区，本轮向上配对证据不能早于该日。

按上述工程边界取价，中轴来源是10月20日实际Low7.41，10月27日High7.49只作验证。旧算术实现得到H8.07；按当前对数等距公式，H为`7.41²/6.75 = 8.13453333…`。推算端均不参与选择来源区域。10月21日Low7.36保留在来源组证据中，不作为共同区下沿。最终状态及触达与否以同版代码和冻结输入的实际输出为准，不能把价位写成已经获得用户验收。坐标、精度和版本边界见[对数价格口径](price-coordinates.md)。

旧V2的M7.49、H8.23及贝斯特High17.25的图形作为历史核对保留，不视为本轮实际Low次低方法的合格自动样本。V1、V2、V3保留各自规则身份，不能继承为V4已生效锁线。

本轮修订使用独立的V4规则身份与政策哈希，范围是本地共享代码、方法说明及保存行情复核。线上启用是独立动作；需先发布可识别新旧版本的前端，再更新后端并生成新完整批次，仅修改源码或本地绘图不能声称线上已采用V4。

## 五个主要分类

以所标注交易日的收盘价 C 分类。先检查高低边界，再检查附近范围。

| 分类 | 条件 |
| --- | --- |
| 突破高点 | `C > H` |
| 跌破低点 | `C < L` |
| 中轴附近 | `abs(C - M) / M <= 2%` |
| 低点附近，收盘未跌破 | `L <= C <= 1.02L` |
| 高点附近，收盘未突破 | `0.98H <= C <= H` |

多个范围重叠时保留全部附近标签，主类采用比例距离最近的一条；精确同距单列“多线同距”。选点本身存在竞争而未画线时仍归“无合理画法”，不与价格同距混淆。远离三线、历史结构、无合理画法和数据不足可从“更多分类”查看。

盘中触及H／M／L、上破H后回落、下破L后收回分别显示。近高／近低默认表示收盘未越线；“近高／近低只看盘中也未越线”开关可排除影线越线收回。分类距离以完整精度计算，页面价格格式化不改变比较结果。

## 每日结构与时间

每日先用开盘前已生效的旧结构给当天K线分类，再检查下一交易日候选。新组合保留实际计算批次时间和生效日；生效日不早于实际计算日后的下一个官方交易日。

首次发布或缺少已生效旧锁线时，可以显示“当前收盘位置参考”，不声称它在历史上已被锁定，也不补造“今日新突破”。只有同一旧结构、有连续交易日前收且当日已经生效，才标明今日新跨线。结构当天结束仍保留当天位置事件；后续归历史复盘，参考线止于首触或失效日。

原始历史 `known_at` 保持未知。批次开始时间、实际发布时间、生效交易日和证据K线日期分别保存。未完成批次跨北京时间自然日重新生成代次，避免恢复时倒填生效时间。

## 数据与发布

`backend.golden_projection.daily` 读取现有 `data/chips/daily/manifest.json` 对应的完整股票清单与不可变个股日线，并在同一发布租约内准备上证指数与创业板指数的日线。股票来源、筹码、趋势筛选、固定20样本及人工批注保持原路径。

指数仅请求 BaoStock `sh.000001`、`sz.399006` 的日线字段。价格使用指数点位，成交量沿用来源的股数口径，原始 SDK 字段与字符串、哈希、实际采集时间和历史 `known_at` 未知状态分别保留。每指数最多400行、原始响应最多1MiB，采集最多120秒且计入原900秒总预算；同日已验证的缓存直接复用。来源窗口只用于取得画线所需的实际历史，不补造缺日。

指数输入使用独立的 `stock.golden-projection.index-source.v1` 合同，保存在私有 `data/golden-projection/daily/index-inputs/` 及 `index-snapshots/` 内。输入指纹进入早退判断及结果批次身份；目录单列 `index_symbols`、`index_source_dataset_id`、股票数和指数数。指数详情绑定指数快照，股票详情继续绑定原股票来源。首次引入的指数没有昨日画线时生成当前参考组合；已有目录声明包含该指数却缺少旧详情时，仍保留缺失或损坏处理。

指数来源尚未到目标日或暂时失败时，可发布明确的数据不足状态，后续取得有效输入会生成新批次；存储故障则中止本次发布并保留上一完整批次。认证只增加两个精确指数结果 GET 路径，内部来源和快照路径不对网站开放。

结果使用独立私有前缀 `data/golden-projection/daily/`：状态、最新目录、按批次保存的筛选表和个股详情。全部股票有明确结果后，先核对不可变文件，再以ETag条件提交最新目录；缺少或损坏行情保留数据不足，不能据此确认停牌。临时存储故障中止本轮而不封存不可变的失败股票，重跑可以恢复。失败或来源尚未齐备时保留上一完整批次。

上限为当前来源清单最多10000股、8个默认工作线程、900秒和1GiB来源传输；不得将部分计算替换为全量完成。来源清单尚未独立核定时，页面称“当前网站股票清单”，不宣称完整全A股覆盖。

`.github/workflows/golden-projection.yml` 在原每日筹码工作流完成后触发，并于北京时间21:40和次日02:40补查。集中度尾段失败不阻止读取已经完整发布的行情；来源尚未到目标日时继续等待。沿用原OIDC角色、私有S3和登录服务；独立并发组及租约避免同前缀多写。日更是否实际完成，以已发布行情日期、状态及成功运行证据判断。

新数据仅增加登录后的精确GET路径，不开放写API、内部租约、批次元数据或公开行情文件。没有交易执行、收益检验或买卖建议。
