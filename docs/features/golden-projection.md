# 每日黄金画线与位置分类

入口为 `/golden/daily`，主导航显示“每日画线”。原 `/golden` 的固定20样本、人工画线和批注继续保留，通过“人工核对工作台”进入。

## 画线依据

先检查当前波段与父子层级，再检查中轴。中轴可以来自有意义的支撑／阻力反应，也可以来自有明确来路和右侧反向证据的次高／次低，两条路径不要求同时满足。

- 高点 H 与中轴 M 推算低点：`L = 2M - H`。
- 低点 L 与中轴 M 推算高点：`H = 2M - L`。
- 中轴和原点取实际K线字段，推算端与实际端分别标明，不平均价位或按未来极值倒推中轴。
- 从原点到选点证据齐备时已经走过推算端，先复查预先形成的父子波段和独立候选。不能沿历史价格向左搜索直到公式通过。
- 原点或中轴归属冲突、同等候选竞争、反向证据不足时不画；详情保留原因及被拒候选。

计算使用最近60根实际日线，最多显示120根背景。左右各2根局部转折仅生成候选，不能独自证明阶段重要性。完整反应、结构延续及角色证据提供额外检查；这是一版保守的自动工程解释，不能称为对所有人工视觉判断的完全复现。具体工程定义保存在 `backend/golden_projection/policy.json`，参数哈希随结果发布。2%只用于展示距离，不作为支撑阻力聚类容差。

## 五个主要分类

以所标注交易日的收盘价 C 分类。先检查高低边界，再检查附近范围。

| 分类 | 条件 |
| --- | --- |
| 突破高点 | `C > H` |
| 跌破低点 | `C < L` |
| 中轴附近 | `abs(C - M) / M <= 2%` |
| 低点附近，收盘未跌破 | `L <= C <= 1.02L` |
| 高点附近，收盘未突破 | `0.98H <= C <= H` |

多个范围重叠时保留全部附近标签，主类采用比例距离最近的一条；精确同距单列“多线同距”。选点本身存在竞争而未画线时仍归“无合理画法”，不与价格同距混淆。远离三线、历史结构、无合理画法和数据不足可从“更多分类”查看。

盘中触及H／M／L、上破H后回落、下破L后收回分别显示。近高／近低默认表示收盘未越线；“近高／近低只看盘中也未越线”开关可排除影线越线收回。分类距离以完整精度计算，页面价格格式化不改变比较结果。

## 每日结构与时间

每日先用开盘前已生效的旧结构给当天K线分类，再检查下一交易日候选。新组合保留实际计算批次时间和生效日；生效日不早于实际计算日后的下一个官方交易日。

首次发布或缺少已生效旧锁线时，可以显示“当前收盘位置参考”，不声称它在历史上已被锁定，也不补造“今日新突破”。只有同一旧结构、有连续交易日前收且当日已经生效，才标明今日新跨线。结构当天结束仍保留当天位置事件；后续归历史复盘，参考线止于首触或失效日。

原始历史 `known_at` 保持未知。批次开始时间、实际发布时间、生效交易日和证据K线日期分别保存。未完成批次跨北京时间自然日重新生成代次，避免恢复时倒填生效时间。

## 数据与发布

`backend.golden_projection.daily` 仅读取现有 `data/chips/daily/manifest.json` 对应的完整股票清单与不可变个股日线，不调用行情提供商，不改变筹码、趋势筛选、固定20样本或人工批注。

结果使用独立私有前缀 `data/golden-projection/daily/`：状态、最新目录、按批次保存的筛选表和个股详情。全部股票有明确结果后，先核对不可变文件，再以ETag条件提交最新目录；缺少或损坏行情保留数据不足，不能据此确认停牌。临时存储故障中止本轮而不封存不可变的失败股票，重跑可以恢复。失败或来源尚未齐备时保留上一完整批次。

上限为当前来源清单最多10000股、8个默认工作线程、900秒和1GiB来源传输；不得将部分计算替换为全量完成。来源清单尚未独立核定时，页面称“当前网站股票清单”，不宣称完整全A股覆盖。

`.github/workflows/golden-projection.yml` 在原每日筹码工作流完成后触发，并于北京时间21:40和次日02:40补查。集中度尾段失败不阻止读取已经完整发布的行情；来源尚未到目标日时继续等待。沿用原OIDC角色、私有S3和登录服务；独立并发组及租约避免同前缀多写。日更是否实际完成，以已发布行情日期、状态及成功运行证据判断。

新数据仅增加登录后的精确GET路径，不开放写API、内部租约、批次元数据或公开行情文件。没有交易执行、收益检验或买卖建议。
