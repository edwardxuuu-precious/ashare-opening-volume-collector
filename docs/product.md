首屏保留股票、日期、必要单位、数据同步状态和结果。单只单日展示占比、开盘量、全天量和收盘价；多记录展示中位数、最高、最低及可计算数量。公式、覆盖和列口径使用说明按钮，电脑支持悬停，点击、键盘与手机点按也可展开；完整方法保留在折叠的「口径与来源」。错误、缺失和未保存记录在结果区明确提示，刷新失败只保留同一查询的上次结果。

多日查询展示趋势图：指定不超过5只股票时逐只绘线，更多股票或全市场显示筛选结果的每日中位数。中位数不以成交量加权，缺失记录留空，各日可计算数量显示于提示，日期轴只包含选中交易日。明细表保留日期、占比、开盘量、全天量、开/收、高/低、涨跌幅、振幅及状态；单只查询省略重复股票列。点交易日期展开精确股数、完整日行情及来源，正常价格固定两位小数；日行情在表格、单日概况与明细弹窗共用完整性判断，缺失或确认无成交留空，不显示零。涨跌红绿区分，振幅不显示多余正号。表格每页50条。

手机端将紧凑股票栏置于结果上方，已有股票时收起搜索，点击搜索图标展开。日历和说明面板在屏幕内滚动，表格横向滚动时固定日期列。日历显示已保存圆点，休市日禁用。当前网页只查询后台已保存的交易日；未保存日期明确提示不可查询，不在访问时启动采集。独立 Scheduler 分发后台采集，网页显示已发布状态。保留的本地按需服务说明见 [开发服务](development/service.md)，该服务没有接入生产页面。

停牌、退市程序、换股吸收合并、重大资产重组或控制权变更等特殊情况通过「状态」列图标展开，包括类别、停牌起始日、具体原因和依据入口。沪市缺口由上交所停复牌接口按目标日核对；已逐份复核的公司公告可提供更细分的说明。行情源空响应、`ST` 名称或公告关键词本身都不足以确认停牌；证据不足时仍显示「数据待补」，不猜测原因。处于退市程序的股票在交易所正式终止上市前不标记为「已退市」。

同步状态栏只显示最后一次成功同步的日期时间（北京时间）和当前数据状态。处理数量、待补数量、历史积压、重试时间及采集诊断保留在后台状态数据中，不在该栏展示。采集任务结束不等于数据齐全；上午预采完成显示等待收盘数据，仍有缺失时显示部分数据待补齐。

## 指标

比例 = AKShare 新浪 09:45 首根 15 分钟 K 线量 / 同日全天成交量 × 100%，统一按股计算。当天全天量在 15:30 后取自一次新浪全市场快照，历史补数取新浪不复权日线；不做跨来源核对，也不因全天分钟合计差异排除可计算记录。首根所含竞价沿用来源口径，不自行补减。来源明确提供开盘量为0、且同日全天量为正数时，按既有download_only规则计算0%；空响应、缺失、无效数值及全天零量不生成正常比例。

日行情保存不复权的 `open / high / low / close`，单位为元/股。四个价格作为一个原子行情帧：只有全部为有限正数，且满足 `low <= open <= high`、`low <= close <= high` 时才标记为可用；任一字段缺失或关系非法时四个字段统一留空，禁止混合不同来源的局部字段。停牌、退市程序或其他确认无成交记录同样留空，并由独立状态和正式证据说明原因，绝不写成四个零。2026-09-21 起的新交易日必须同时完成原有核心数据和日行情才视为最终健康；2026-03-06 至 2026-09-18 的旧记录由独立回填逐批补齐，不反向破坏原有核心完成状态。

涨跌幅与振幅来自与 OHLC 相同的行情帧：涨跌幅 = (当日收盘 − 上一交易日收盘) / 上一交易日收盘 × 100%；振幅 = (当日最高 − 当日最低) / 上一交易日收盘 × 100%。缺少前收或最高最低时留空，不影响开盘占比；历史已保存数据由回填脚本补齐，新采集按同一口径直接写入。

名单取采集当天在市 A 股快照，含沪深北，不冒充历史当日全体上市股票。近期上市、停牌或来源不全会产生缺失项。实际样本及原始响应核对见 [历史数据验证](verification/data.md)。

## 每日筹码筛选

独立导航 `/chips` 每日扫描沪深京当前在市股票，仅保留近10个交易日至少一次收盘涨停、收盘价高于平均成本、顶格未动三项。2026-10-25用户取消全部绝对价格条件，10元以上、以下和恰好10元均不受价格门槛排除；高于主峰也不能替代高于平均成本。平均成本按完整精度严格比较，等于不通过。“顶格未动”暂无已确认的自动判定标准，保持UNKNOWN并待人工核实，前两项通过不标为最终入选。缺失数据同样待核实。当前改动仅本地验证，发布及真实每日批次另行验收。

筹码模型 `chip-estimate.eastmoney-nodes150.ohlc4.zero-start.decay2.window210.v1` 每批加载最近210根已观测有效日线，从零开始，三角顶点使用OHLC四价均值；网格为150个动态节点，步长 `max(0.01,(窗口最高-窗口最低)/149)`。历史衰减系数固定2，同一个 `A=min(1,2×换手率/100)` 用于历史衰减和直接采样高度注入，不先将每日注入归一化为1。只有展示占比才除以累计总质量。

两日使用同一210根窗口的各自前缀独立回放，前日通常有209根；上市不足210根时展示实际根数，不补造行情。原峰占比按昨日未舍入峰节点±昨日半步长的固定区间跟踪；新高导致网格变化时重新按价格选择节点，不沿用旧下标。个股页面显示日K线、对应成交量及共用价格轴的右侧筹码，并列出原峰占比与每日百分点变化。

图表随容器宽度重排，K线、下方成交量和右侧两日筹码在同一个画布内展示，不再要求横向滚动；价格标签与日期刻度保持可读，窄窗口减少日期刻度数量。可切换60/120/250/500日，悬停查看当日价量，所选筹码日期明确标注。窄窗口筛选名单按股票分行显示全部字段，原峰占比表同步适配。

点击某根K线或使用“筹码日期”选择框，右侧分布、主峰对比及原峰固定价格区间占比同时切换到所选日期；“前一交易日”“后一交易日”按该股票已有的可用交易日期连续切换，首尾日期自动禁用对应按钮，加载期间仍可继续切换并仅显示最终所选日的数据；“回到最新”恢复当前发布批次。悬停K线或对应量柱时临时预览该日筹码、主峰和原峰占比变化，日期框保留已固定日期，图表另标“鼠标预览”；点击固定该日，移出图表恢复已固定日期。悬停不改变换股保留的日期或K线显示区间。历史回放每次取截至所选日的最近210根有效行情，前一交易日使用相同窗口前缀，零初始化、系数2及150动态节点不变；因此单独回放某历史日的210根窗口，可能与后续批次中同日的209根前缀略有差异。最新视图直接使用已封存的每日快照，与筛选名单保持一致。

较早日期的筹码按需从已保存行情回放，首次读取可能短暂等待；图内右侧明确显示加载日期或失败状态，不能把等待当作数据缺失。相邻交易日会提前准备，已查看日期缓存复用，连续预览共用在途请求；换股时结束旧股任务。

打开个股详情后，键盘左/右方向键与“前一交易日”“后一交易日”按钮共用同一日期切换逻辑；上/下方向键按当前筛选和搜索名单的完整顺序切换上一只/下一只股票，并定位到股票所在分页。股票和日期的首尾均不循环越界；当前股票不在名单时，下键从首只、上键从末只开始，空名单不切换，详情显示当前名单位置。换股保留所选历史日期；新股无该日可用K线时明确提示并从最新日期开始，最新视图换股仍显示最新。K线标记、价量、筹码分布、主峰及原峰占比变化同步更新；连续换股期间旧请求取消且不显示其他股票的数据。输入框、日期选择框、可编辑区域及使用方向键的选择控件/弹窗保留原有键盘操作；组合键、输入法组字和已被其他控件处理的事件不触发快捷导航。关闭详情时移除快捷键并恢复最新日期偏好。

历史请求只读取已保存、与该股票发布原件哈希绑定的行情，不临时从供应商下载或改写每日结果。500根K线中较早日期需要的起算行情从私有原件恢复，不能将显示截断误当成上市不足210根。缺少前一交易日行情且无明确未交易证据时，只展示当日筹码并提示对比不可用；缺少当前输入时显示错误，不沿用其他日期的分布。

四股2026年10月13—16日的冻结对照已与东方财富本地系数2源码逐项一致；这不是官方客户端全部设置或真实持仓的认证。每日结果的算法版本、实际窗口长度、数据覆盖和待核实数量以发布批次为准。算法版本变化会使旧模型缓存失效，原始行情仍可复用。

动态网格的浮点计算可能在理论零值端点留下极小负尾数。每笔负贡献必须通过分币与节点的精确有理坐标证明属于当日最低或最高价端点，才能在最终输出时归零，并保存原值与贡献日期；其他负值仍拒绝。迁移前一源码的 READY 帧时，必须全窗口重放所有快照并逐项一致，同时保留原计算身份。

当前交易日优先采用腾讯带当日收盘时间、成交量、精确成交额和换手率的完整报价，覆盖历史接口的零量占位或盘中缓存行；原行情与报价原文、哈希、替换行一并保留。正成交量但数据不完整的报价不能被当作停牌，也不能沿用昨日筹码冒充今日结果。过去日期仍按已归档的真实日线与涨停证据核实。

OHLC4模型保留有限数、日期顺序、分币及OHLC顺序、非负量额换手和零成交一致性校验；成交均价超出日内OHLC只记入审计，不再沿用旧VWAP顶点模型的排除规则。大宗等不同交易口径可能产生该现象，模型仍使用原始OHLC、原始供应商换手率，不扣减成交量、不改写成交额，也不注入另一个成交价；具体原因未经独立证据确认时不推断。

## 本地运行

```sh
npm ci
npm run dev
```

生产数据来自认证 API；本地 `public/data` 是可选的旧开发快照，不提交 Git，也不是生产真源。测试使用独立合成 fixture，不依赖该快照。正式采集与验证：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests/python -v
node --experimental-strip-types --test tests/frontend/*.test.mjs
.venv/bin/python backend/scripts/collect.py --full --months 6 --out var/work/market-data --resume
python3 deploy/export_data.py --source var/work/market-data --require-full
NEXT_PUBLIC_AUTH_API=https://api.stock.iteready.com NEXT_PUBLIC_DATA_BASE=https://api.stock.iteready.com npm run build
```

全量采集需数小时；请求限速、有限重试、连续失败熔断。逐股票 checkpoint；同日成功缓存可以续跑，失败项重新请求。首次回填6个月，后续优先更新当天并补持久队列中的历史缺口，已保存的每日行情永久累积，只有近期补采用的工作断点保持六个月窗口。API上游变更或延迟可能使数据更新失败，旧网页继续可查。
