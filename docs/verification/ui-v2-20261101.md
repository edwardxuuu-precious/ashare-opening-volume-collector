## 切页与登录

旧主导航使用整文档链接，每次重新创建 AuthGate。当前 vinext beta.5 的静态托管 RSC 请求返回HTML，也会降级整页导航，单独替换成框架链接无法解决。

现由 SiteRouter 在已验证的 AuthGate 内加载六条明确路由的页面代码。目标代码读取失败时保留原页面与 URL，支持就地重试。导航缓存只保存代码，不保存登录结果、令牌、用户名或行情。

RootLayout 的同步历史引导先于框架监听，仅在 Router 挂载且路径受支持时委托返回、前进。首页查询按实际 URL 恢复，不依赖首页会替换的 history.state。退出或401卸载全部工作台；重新登录后重新加载当前 URL，避免回到最初静态页面。黄金草稿仍按账号与证券隔离。
