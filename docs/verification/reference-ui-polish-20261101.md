## 已交付变化

- 现有共享变量统一为更中性的灰底、辅助底色与选中色，顶栏使用白底和轻分隔。主面板与手机圆角保留原层级。
- 页面栏目标最小高72px，桌面页名18px、手机17px。日期保留标签与数值，去掉独立白色块。
- 共用搜索增加装饰图标，输入左侧留32px，黄金与连续集中度同步生效。分类名称、计数分开对齐，小字保持真实对比度。
- K线读数使用一条浅底区域，强调收盘及涨跌幅。周期组采用2px内边距；原生日期滑杆使用细灰轨道、蓝色滑块，保留键盘、触摸与日期回调。
- 中等窗口的读数行间距为4px，保留35、54、76px读数及对应加载占位。解决了两行自然高度多出0.1875px、周期组使工具栏多出1px的问题，没有修改测试断言或裁掉字段。
