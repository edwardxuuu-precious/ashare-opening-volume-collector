目的：新交易日通过现有自然调度完成采集、私有发布和认证查询；页面准确表达任务状态与已发布数据状态，已保存历史持续可查。

范围：采集接续与重试、任务/发布状态契约、必要的前后端修复、既有目标发布、真实日更验证、数据保存规则核对、Git 与当前阶段收口。原方案 B 的视觉基线继续作为验收基线。

历史说明增强、旧故障精确归因、RSC 日志和域名元数据仍保留原记录；没有新证据表明其阻止 N1–N3 时，不扩大本计划。

## 2. 完成效果与场景

| 场景 | 预期效果 |
| --- | --- |
| 正常交易日开盘预采 | 到达既有预采条件后实际处理目标；未到重试点时有限等待，不能因不断改写重试点而永久不处理 |
| 收盘日更 | 自然调度选择正确已收盘目标，发布真实成交量和完整价格帧；不把上午缓存写成全天数据 |
| 休市或没有到期目标 | 保留最近成功发布；任务没有新工作与数据完整性分别表达 |
| 来源暂不可用 | 保存断点和真实缺口，按既有有限退避接续；未完成不伪装为完整或零量 |
| 运行失败或人为暂停 | 页面状态与失败/暂停的实际证据一致，保持最后成功同步时间 |
| 中断后恢复 | 使用绑定 SHA 的断点继续；成功记录、来源、确认无成交及完整价格帧保持 |
| 登录查询与刷新 | 指定股票、日期和全市场查询保持正常；匿名私有行情访问仍被阻止 |
| 长期历史保存 | 六个月仍是自动补采窗口；窗口之外已保存日文件与目录持续保留 |

## 4. 评估体系

| 层次 | 指标/门 | 合格条件 |
| --- | --- | --- |
| 诊断 | 真实症状反馈循环 | 一条明确命令已在真实 bug 模式上失败；修复后原模式通过，正常退避仍有效 |
| 本地实现 | 受影响调用链回归、静态检查 | 必要测试通过；证据绑定代码版本；不以浅层替身测试代替实际调用链 |
| 部署 | 生产身份、版本、保护构建/源码清单、回退 | 精确目标匹配；线上实际代码/资源与批准执行的候选一致 |
| 采集结果 | 自然触发完整周期 | 有调度、run ID、真实处理、完整发布和认证读回；没有证据则保持待验 |
| 数据正确性 | 目录/正文/目标状态不一致数 | 0；真实缺失不变成零；无成交与价格帧规则保持 |
| 数据保护 | 既有历史记录/来源回退数 | 0；只允许明确核验的新增或必要更新；不滚动删除已保存历史 |
| 状态可信度 | 展示与真源不一致数 | 0；心跳不冒充成功同步；任务等待不冒充已发布完整 |
| 访问保护 | 匿名行情泄露与认证查询回归 | 泄露 0，规定查询场景通过；不更改账号或权限范围 |
| 最终目标 | 八项要求与全部任务逐项审核 | 每项都有直接证据；任何缺失、间接或矛盾证据保持未完成 |

业务留存、商业转化与跨多个交易日的长期可靠性不由一次工程验收推定。现有运行契约的及时性阈值保留，记录实际达成情况；不为通过验收改写阈值。

## 5. 并行与串行边界

并行：日志/代码与状态/保存策略的独立只读核对，互不竞争端口或数据写目标的检查。Coordinator 汇总局部证据。

串行：正式计划和共享状态更新、代码整合、写租约/调度配置、生产采集写入、公开源码/前端发布、Git 与最终 closeout。正在运行的任务继续使用其启动版本，不取消任务、不删除活动租约。必要维护按原手册精确保存并恢复配置。

主路径：`PLAN → N1-01 → N1-02 → N1-03 → N2-03 → N3-02 → N3-03 → N3-04`。N2-01/N2-02 和 N3-01 在证据允许时穿插推进，不解锁尚未通过的生产验收门。

## 6. 数据反馈与有限迭代

每个实际失败绑定稳定 issue ID、场景、run ID/响应/代码版本、已确认与未知原因、最小下一动作及复验结果。索引保存在 `outputs/n123-convergence/stage-state.json`；正文只在对应实现/验收报告记录一次。

迭代只处理 N1–N3 的未通过门：先区分产品、来源、测试 fixture、工具/环境、权限或真源漂移；每次针对有新证据的一条假设修复并复验。无新增证据的重试停止，记录恢复条件；不通过改测试、改状态文案或缩小目标来完成。

任务状态仅在证据支持时由待执行/进行中进入完成。自然周期尚未发生、外部来源尚未返回或人工门未通过时保留待验/阻塞，不以本地绿灯替代生产结果。

## 7. 停止、人工介入与重开

- 生产账号、目标版本、权限或并发 writer 与核验结果不符：停止相关写入，刷新事实后继续。
- 来源缺失或目标尚未满足采集条件：保留真实缺口与有限重试；不能合成行情。
- 凭据/宿主人类认证不可用、必须由账户持有人操作，或出现新增重大成本/产品取舍：先完成可独立工作与具体审阅包，再弹窗请求并等待回复。
- 当前全量推进指令覆盖本计划必要的可逆实现与既有目标修复。已授权步骤不重复请求确认；范围、资源或重大取舍变化时重新提出具体选择。
- 生产数据或访问保护回归：停止发布扩展，按核验保护版本恢复必要代码；保留已正确发布数据与断点。
- 新的连续采集退化、指纹/计数不一致、错误状态或真实读取复现：重开对应任务，不把本次收口作为永久健康保证。
