## 共用实现与保留差异

- `CandleReadout` 统一四价、涨跌幅、量及其顺序。`chart-readout.ts` 保留原成交量单位；不能把未知单位或手转换成股。筹码另有真实换手率，黄金概览缩略图不强加完整读数。
- `ChartPeriodControl` 统一数量标签及行情不足提示。工作台和校准页保存显示周期，黄金业务计算仍使用 60 根。
- `CandleInspectionControl` 和 `useCandleInspection` 使用真实日期及历史身份；鼠标、触摸与原生键盘操作使用同一个检查状态。筹码固定日期与趋势观察日、黄金批次分别保留。
- `useStockListNavigation` 只遍历完整的筛选名单，同步分页、名单滚动和行焦点，保留输入法、组合键、输入控件与弹窗操作。
- `InspectorTabs` 统一活动页签、左右键、Home/End 和面板关联。`RetryMessage` 与 `StockListNote` 统一错误恢复、空名单和列表外选择提示。
- `PopoverContent` 共用固定定位和碰撞平移；手机日历不再因页面自动滚动而把完成按钮移出屏幕。

- 浏览器输入来自隔离快照，数据接口被本地响应接管；全站脚本禁止所有 API 写入。登录脚本只向隔离响应提交虚构账号，不使用正式凭据。以上不能代替正式账号人工验收、模型验证或行情源认证。

全站脚本为 [ui-consistency.cjs](../../tests/browser/ui-consistency.cjs)。使用已安装的 Playwright、隔离快照目录和本地生产构建服务运行：

```sh
NODE_PATH=/path/to/browser-tools/node_modules \
UI_TEST_URL=http://127.0.0.1:4191 \
UI_FIXTURE_DIR=/absolute/path/to/isolated-snapshots \
UI_TEST_OUTPUT_DIR=outputs/ui-consistency-20261101 \
node tests/browser/ui-consistency.cjs
```

`UI_FIXTURE_DIR` 须包含 `fixture-meta.json` 与相应 `data/` 输入；不提交或打包这些快照。输出包含逐项结果与截图。

既有 `query-read-recovery.cjs` 仍引用当前界面已移除的 `.price-backfill-notice` 等选择器，本轮没有将它计为通过。当前查询的刷新保留、初次读取重试、名单重试及记录详情由新全站脚本检查；旧脚本的其余历史场景未在本轮重新认证。
