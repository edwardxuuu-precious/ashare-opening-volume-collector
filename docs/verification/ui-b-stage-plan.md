## 7. 停止、恢复与回退

- AWS 令牌失效：暂停云端调用，完成本地准备；正常登录恢复后复读身份和目标。
- 目标、当前版本或并发部署变化：停止发布，复核新的真实状态，不能沿用旧发布确认覆盖其他版本。
- 候选或回退包含公开行情、fixture 地址，或归档指纹不符：停止并重新形成可审阅保护包。
- 平台响应不确定：沿用已记录 job 核对结果，不创建重复部署。
- 线上身份边界、资源或实际查询失败：停止验收扩展；在授权的静态前端范围内按已核验保护包回退或完成最小修复。
- 新版原机验收未取得：保留待验收状态；不能将整项升级标记成功或将目标标记 complete。
