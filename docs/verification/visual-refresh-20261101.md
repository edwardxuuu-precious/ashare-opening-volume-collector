# 量序视觉升级核验

2026-11-01 在 UI v2 的共用字段、布局和状态结构上升级视觉。覆盖开盘量查询、每日筹码、每日趋势、历史趋势研究、黄金画格、历史筹码校准及登录入口。约束真源为[界面约束](../ui-guidelines.md)。

## 已发布的变化

- 比较平面与柔和面板两组候选后，采用浅灰画布、白色主面板和分段导航。按照 Experience First 保留有效图表空间，减少重复边框，指标使用一组浅底区域。
- 共用 Inter 与 Noto Sans SC、分级圆角、字号、间距和阴影。主面板桌面20px、手机16px，控件10px，名单行12px。两类主图与加载占位共用图高变量。
- 查询概况在1180px及以下改成两列，避免成交量数字重叠。研究页签不压缩，键盘切换时滚入可见区域；研究、黄金和校准的旧控件覆盖规则已统一。
- 登录入口使用同一浅灰背景与圆角表单，移除大幅彩带。行情计算、筛选规则和认证权限沿用原实现。
