## 成本与停用

保留公开仓库标准免费 runner，未新建 EC2、EBS、NAT 或收费数据源。独立分发器预计每月约 6,417 次、128 MB，正常新增低于 $0.50/月；这不是硬扣费上限。09-01 至 09-08 账号账单已只读核对，包含已退役 EC2 的历史费用，不能直接当作新架构月费；部署调度前还需合并存储、出网、站点和其他项目占用，守住约 10–20 元预算。

页面控制轮询本身不触发行情采集。单个持续可见、但采集已结束的标签页由 360 次/小时降为 72 次/小时；控制响应量由约 44.5 MiB/小时降为约 0.41 MiB/小时，隐藏标签页为 0。以当前 512 MB Lambda 最近 24 小时实测平均 336 ms 和 AWS 美东公开单价保守计算，不计免费额度时，单标签页全天可见的控制轮询约低于 $0.30/月；实际使用按可见时长线性下降。日文件只在目录版本变化时读取，收盘发布期最多每 2 分钟一次；用户量明显增加时需用 API Gateway/Lambda 账单告警重新验收，不把估算当硬限额。

停用优先设置仓库变量 `DISABLE_DAILY_UPDATE=true`，并禁用独立四个 Scheduler（部署后）。不通过删数据、删断点或解除活动租约停用。网站可回滚到上一份 `outputs/download-only/website.zip`；不回滚已正确补齐的行情。
